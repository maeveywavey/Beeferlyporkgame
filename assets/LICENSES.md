# Third-party art

All models, textures and animations in this folder (except `fonts/`) were made by **Quaternius**
(https://quaternius.com, https://www.patreon.com/quaternius) and are released
under **CC0 1.0 Universal (public domain)**:
https://creativecommons.org/publicdomain/zero/1.0/

| Folder | Source pack |
|---|---|
| characters/base, characters/hair | Universal Base Characters (Standard) |
| characters/outfits | Modular Character Outfits - Fantasy (Standard) |
| characters/culture | recoloured from the outfit textures by tools/prepare_assets.py |
| animations | Universal Animation Library 1 and 2 (Standard) |
| nature | Stylized Nature MegaKit (Standard) |
| props | Fantasy Props MegaKit (Standard) |
| animals/Horse.fbx, Cow.fbx, Llama.fbx | LowPoly Animated Animals (farm animal pack) — https://quaternius.itch.io/lowpoly-animated-animals |
| animals/Triceratops.fbx | Animated LowPoly Dinosaurs (Dec 2018) — https://quaternius.itch.io/animated-lowpoly-dinosaurs |

Textures were downsized for repository size. CC0 requires no attribution, but
the artist deserves it: thank you, Quaternius.

## Fonts (`fonts/`)

Licensed under the **SIL Open Font License 1.1**. Each family's licence text is
in `fonts/OFL-*.txt`. They are bundled unmodified, from the Google Fonts
repository (https://github.com/google/fonts).

| Font | Designer | Used for |
|---|---|---|
| Alegreya, Alegreya Italic (variable) | Juan Pablo del Peral, Huerta Tipográfica | Body text |
| Alegreya SC (Medium, Bold) | Juan Pablo del Peral, Huerta Tipográfica | Titles, headings, buttons |
| Atkinson Hyperlegible | Braille Institute of America | The "Readable font" setting |
| Ma Shan Zheng | Ma Shan Zheng | The one-character seals |

The interface's paper, lacquer, gold-leaf and brush textures are generated in
code (`scripts/ui/skin.gd`). The title-screen landscape is a shader
(`shaders/ink_wash.gdshader`).
